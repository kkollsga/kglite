# Security Policy

## Which channel to use

| Report | Channel |
|---|---|
| Bugs, wrong results, crashes, feature requests | [Public issues](https://github.com/kkollsga/kglite/issues/new/choose) |
| Security vulnerabilities | [Private vulnerability reporting](https://github.com/kkollsga/kglite/security/advisories/new) |

Public issues are the default for everything that is not a vulnerability.

## Reporting a Vulnerability

Report a vulnerability privately, not in a public issue.

- Use [GitHub's private vulnerability reporting](https://github.com/kkollsga/kglite/security/advisories/new), or open the **Security** tab and click **Report a vulnerability**.
- Only the maintainers and you can see the report.
- Examples: memory corruption, a bypass of an access or authentication check, reading files outside the configured sandbox.

We acknowledge a report within 48 hours.
We aim to release a fix for a critical issue within 7 days.
The advisory is published once the fix is released.

## Supported Versions

Only the latest released version receives security updates.
